# Security policy

## Reporting a vulnerability

Report vulnerabilities privately using **Security → Report a vulnerability**
on the published repository. Do not include vulnerability details in public
issues. Include what an attacker needs (network position, credentials), the
impact, and a reproduction if you have one.

You will get an acknowledgement within a week. Fixes are released as soon as
they are ready, and credited in the advisory unless you prefer otherwise.

## Supported versions

Security fixes go into the latest release. Svart is young; there are no
long-term support branches yet.

## What Svart defends against

The threat model, the defaults that implement it and the results of past
reviews are in [docs/security/](docs/security/README.md).
