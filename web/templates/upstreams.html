Supported formats:
  • 94.140.14.140, 2a10:50c0::1:ff - UDP DNS
  • 94.140.14.140:53, [2a10:50c0::1:ff]:53 - UDP DNS with port
  • udp://unfiltered.adguard-dns.com - UDP DNS with hostname
  • tcp://94.140.14.140, tcp://unfiltered.adguard-dns.com - TCP DNS
  • tls://unfiltered.adguard-dns.com - DNS-over-TLS
  • https://unfiltered.adguard-dns.com/dns-query - DNS-over-HTTPS
  • h3://unfiltered.adguard-dns.com/dns-query - DNS-over-HTTPS (HTTP/3)
  • quic://unfiltered.adguard-dns.com - DNS-over-QUIC
  • sdns://... - DNS Stamps (DNSCrypt/DoH)
  • [/example.local/]94.140.14.140 - Domain-specific upstream
