# DD-033: Upstream exchange hardening

**Decision**: Every upstream exchange sends a message svart builds itself: a crypto/rand ID, the lowercased question as class IN, RD=1, CD/AD from the client, and svart's own EDNS0 (UDP 1232, DO only if the client set it). Client EDNS options (ECS, cookies) are never forwarded. A reply is used only if it is a response with the same ID, opcode QUERY and exactly the question sent; anything else counts in `svart_dns_upstream_mismatched_replies_total` and fails the exchange. A TC=1 UDP reply is retried over TCP. DoT verifies the configured hostname (TLS 1.2+) while dialing the bootstrap IP. DoH uses one long-lived HTTP/2 client per upstream. TCP and DoT keep up to 4 idle connections per upstream, each used by one exchange at a time. UDP keeps a fresh socket per exchange behind a global cap of 4096 in-flight exchanges that fails fast (`svart_dns_upstream_saturated_total`, SERVFAIL). Bootstrap lookups honor the request context, read servers through `readDB`, validate the reply and cache failures for 10 s.

**Why**: The old path forwarded the client's own message, so an attacker chose the upstream ID and ECS leaked client subnets. It accepted any reply to that ID, which let a reply for another name poison the cache. It verified DoT certificates against the spoofable bootstrap IP and paid a TLS handshake per DoH/DoT query. A shared pool of connected UDP sockets with ID demux was rejected on purpose: fixed source ports throw away the ~16 bits of entropy that a random ephemeral port per query adds to the 16-bit ID, and that is the off-path spoofing defense this decision exists for. The in-flight cap bounds the socket cost instead. 0x20 case randomization was not adopted: it only adds entropy with an exact-case reply check, and that needs a fallback path for forwarders that fold case, such as the routers DD-030 forwards to.

**Revisit if**: The in-flight cap is hit under legitimate load (watch `svart_dns_upstream_saturated_total`), DoT upstreams need pipelining for throughput, or 0x20 becomes worth its fallback complexity.
